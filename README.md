# J&C — Nail Design Studio

Landing page estática do studio J&C, com portfólio, catálogo de serviços e agendamento pelo WhatsApp.

## Desenvolvimento

Sem dependências ou etapa de build. Para visualizar localmente:

```sh
python3 -m http.server 8000
```

## Publicação

GitHub Pages publica a raiz da branch `main`. Os arquivos `.nojekyll` e `index.html` permitem servir o site diretamente.

Fotografias e identidade visual da J&C. Fontes Cormorant Garamond e DM Sans carregadas pelo Google Fonts.
